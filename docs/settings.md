# 系统配置

AI 模型、API 密钥等系统设置。

---

## 功能说明

系统配置页面用于管理所有 AI 模型连接、API 密钥和应用全局设置。在使用任何 AI 功能之前，必须先完成系统配置。

---

## 配置项说明

### 文案生成模型设置

用于所有文本生成任务（分镜描述、解说脚本等）。

| 配置项 | 说明 |
|--------|------|
| 模型名称 | 如 gpt-4o, deepseek-chat 等 |
| API 密钥 | 模型的 API Key |
| 接口地址 | API 地址，如 https://api.openai.com/v1 |

### 视频分析模型设置

用于视频内容分析。

| 配置项 | 说明 |
|--------|------|
| 模型名称 | 视频分析使用的模型 |
| API 密钥 | API Key |
| 接口地址 | API 地址 |

### 图片生成模型设置

用于漫画图片生成。

| 配置项 | 说明 |
|--------|------|
| 模型名称 | 如 gpt-image-2, gpt-image-2-pro 等 |
| API 密钥 | API Key |
| 接口地址 | API 地址 |
| API 供应商 | NewAPI / ToAPI / Grasai / JiKe / ManXiaoBai |
| 接口类型 | OpenAI / Gemini |

> 不同供应商的接口地址和请求格式不同，请根据实际使用的 API 选择正确的供应商。

### 语音配置

| 配置项 | 说明 |
|--------|------|
| 豆包语音 | Access Key、Secret Key、App ID、Token |
| 腾讯 ASR | SecretId、SecretKey、Region |

### 全局设置

| 配置项 | 说明 |
|--------|------|
| 草稿输出目录 | 生成文件的默认保存路径 |
| GPU 加速 | 启用视频编码的 GPU 硬件加速 |

---

## 操作流程

### 1. 进入配置

左侧导航栏点击「系统配置」。

### 2. 填写配置

1. 按需求填写各模型配置信息。
2. 建议先点击「测试连接」验证 API 有效性。
3. 图片生成配置可点击「测试生图」验证生图功能。

### 3. 保存配置

点击页面底部的「保存配置」按钮，配置会自动持久化。

## 常见问题

**Q: 测试连接失败？**  
A: 检查 API Key 是否正确，接口地址是否与供应商提供的一致。

**Q: API Key 如何复制？**  
A: 选中密码框中的内容后按 Ctrl+C 即可复制。

**Q: 配置保存后重启丢失？**  
A: 配置保存在本地数据库中，通常不会丢失。如遇问题可检查数据库文件是否正常。
