## 快速入门

1. **配置 AI 模型**：首次使用请先进入 [系统配置](settings.md)，配置文本模型和图片生成模型的 API Key。
2. **选择功能**：在左侧导航栏选择需要的功能。
3. **导入素材**：根据功能提示导入视频或文本素材。
4. **开始处理**：按各功能的操作流程逐步进行。

> 提示：每个功能页面都包含完整的操作流程说明，如有问题可参考对应文档。
