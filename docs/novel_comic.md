# 漫画生成

小说文本自动生成漫画分镜与图片。

---

## 功能说明

漫画生成功能将小说文本转化为漫画分镜描述，再通过 AI 生图模型生成对应的漫画图片。支持资产提取、分镜描述生成、批量生图等完整流程。

---

## 操作流程

### 1. 项目创建

1. 左侧导航栏点击「漫画生成」。
2. 在项目列表页面点击「新建项目」。
3. 填写项目信息：
   - **项目名称**：自定义项目名称
   - **选择小说**：点击选择需要制作漫画的小说文件（TXT 格式）
   - **章节选择**：选择要处理的章节
4. 点击「确定」创建项目。

### 2. 资产提取

进入项目后，第一步是提取漫画资产。

1. 点击「资产提取」按钮。
2. AI 会自动分析文本，提取三类资产：
   - **人物**：所有角色及其外观描述
   - **场景**：出现的场所和环境
   - **道具**：重要的物品
3. 提取完成后，可以查看和编辑资产列表。

#### 资产管理

| 操作 | 说明 |
|------|------|
| 编辑 | 修改资产的名称和描述 |
| 删除 | 移除不需要的资产 |
| 生成资产图 | 为每个资产生成参考图片 |
| 重新提取 | 让 AI 重新分析文本提取资产 |

> 建议为每个资产生成参考图，能够让后续的分镜生图更准确。

### 3. 分镜编辑

资产提取完成后，进入分镜编辑页面。

#### 3.1 绑定资产

1. 在编辑面板中为每个分镜绑定资产：
   - **场景**：选择该分镜使用的场景资产
   - **人物**：选择该分镜出场的人物
   - **道具**：选择该分镜涉及的道具
2. 每个分镜可以绑定不同版本的资产（如"顾晚-常服版"）。

#### 3.2 生成分镜描述

1. 点击「AI 生成分镜描述」。
2. AI 会根据原文和已绑定资产自动生成分镜描述，包括：
   - 动作/表情：描述该格画面中的视觉内容
   - 气泡：对话内容
   - 说明框：旁白和叙事内容
3. 可以手动编辑 AI 生成的描述。

#### 3.3 编辑格

每个分镜支持多格排版：

- 点击「添加格」增加格数。
- 拖拽调整格顺序。
- 设置每格的景别和角度。
- 编辑每格的气泡和说明框。

### 4. 图片生成

#### 4.1 单张生图

1. 在分镜列表中点击「生成图片」。
2. 生成任务会自动进入队列。
3. 图片生成完成后，卡片上会显示生成的漫画图。
4. 如果不满意图片：
   - **重新生成**：使用相同描述重新生成
   - **图片编辑**：在当前图片基础上修改
   - **文字修复**：修复图片中的文字

#### 4.2 批量生图

1. 勾选需要生图的分镜（支持全选）。
2. 点击「批量生图」。
3. 系统会自动排队处理，并显示生成进度。

#### 4.3 生图设置

| 设置项 | 说明 |
|--------|------|
| 图片比例 | 1:1、3:4、9:16 等 |
| 分辨率 | 1K、2K、4K |
| 画风垫图 | 使用参考图统一画风 |
| 全局前缀 | 所有生图统一添加的前缀提示词 |

### 5. 查看与导出

1. 在漫画预览区查看完整的分镜列表。
2. 可以放大查看每张图片的细节。
3. 支持导出图片到本地。

## 分镜描述优化

分镜描述直接影响生图质量，建议注意以下几点：

### 动作/表情

```
✅ 正确：苏渺眼睛瞪大，整个人僵在椅子上。
❌ 错误：苏渺：眼睛瞪大，整个人僵在椅子上。
```

- 使用自然句描述，不用冒号标签。
- 只描述静态画面中能看到的内容。
- 第一句必须指明场景名称。
- 不要使用动词描述动态过程。

### 旁白筛选

只将以下内容放入旁白：
- 内心想法、心理活动
- 动作过程叙述
- 人物身份/关系说明
- 因果逻辑说明
- 转场/时间过渡

环境描写、纯外观罗列不进旁白。

### 气泡格式

```
✅ 正确：顾晚-常服版的气泡："你好吗？"
❌ 错误：顾晚的气泡："你好吗？"
```

气泡名称必须使用资产列表中的完整版本名称。

## 常见问题

**Q: 资产提取不准确？**  
A: 可以手动编辑资产描述，或者点击「重新提取」让 AI 重新分析。

**Q: 生图失败？**  
A: 检查系统配置中的图片生成模型是否正确配置，以及 API Key 是否有效。

**Q: 图片效果不理想？**  
A: 可以优化分镜描述，添加画风垫图，或者在生图设置中调整全局前缀。
