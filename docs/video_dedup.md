# 视频处理

去重、预处理等视频处理工具。

---

## 功能说明

视频处理功能提供视频去重检测、格式转换、预处理等功能，帮助在剪辑前对视频素材进行统一处理。

---

## 操作流程

### 1. 选择功能

左侧导航栏点击「视频处理」，进入处理工具列表。

### 2. 视频去重

1. 选择「视频去重」模式。
2. 导入需要检测的视频文件。
3. 点击「开始检测」。
4. 系统会自动分析视频内容相似度。
5. 标记重复视频，可选择删除或移动。

### 3. 视频预处理

1. 选择「预处理」模式。
2. 导入需要处理的视频。
3. 设置处理参数：
   - 分辨率调整
   - 帧率设置
   - 编码格式
   - 画面裁剪
4. 点击「开始处理」。

### 4. 导出结果

处理完成的视频会保存到指定输出目录。

---

## 去重检测原理

| 检测方法 | 说明 |
|---------|------|
| 画面哈希 | 基于视频帧的画面特征对比 |
| 音频指纹 | 基于音频特征的相似度检测 |
| 混合模式 | 画面+音频综合对比 |

---

## 注意事项

- 视频去重检测需要消耗较多计算资源。
- 建议使用 GPU 加速处理。
- 大量视频处理时请预留足够的磁盘空间。
